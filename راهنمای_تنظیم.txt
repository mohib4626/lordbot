راهنمای تنظیم ربات ادممبر جدید
================================

مراحل تنظیم ربات:

1. تنظیم اکانت‌های تلگرام:
   - فایل accounts_new.json را باز کنید
   - اطلاعات اکانت‌های تلگرام خود را وارد کنید:
     * API ID (از my.telegram.org)
     * API Hash (از my.telegram.org)
     * شماره تلفن
     * نام سشن

2. تنظیم گروه‌ها:
   - فایل config_new.json را باز کنید
   - گروه‌های منبع و هدف را تنظیم کنید:
     * source_groups: گروه‌هایی که اعضا از آن‌ها گرفته می‌شوند
     * target_groups: گروه‌هایی که اعضا به آن‌ها اضافه می‌شوند

3. اجرای ربات:
   - فایل QUICK_START_جدید.bat را اجرا کنید
   - یا فایل start_new_bot.bat را اجرا کنید

نکات مهم:
- از my.telegram.org API ID و API Hash دریافت کنید
- شماره تلفن‌ها را با فرمت بین‌المللی وارد کنید
- نام گروه‌ها را دقیق وارد کنید
- محدودیت‌های تلگرام را رعایت کنید

فایل‌های موجود:
- advanced_member_adder_new.py: ربات اصلی
- accounts_new.json: تنظیمات اکانت‌ها
- config_new.json: تنظیمات ربات
- requirements_new.txt: نیازمندی‌ها
- start_new_bot.bat: فایل راه‌اندازی
- QUICK_START_جدید.bat: راه‌اندازی سریع
- README_جدید.md: راهنمای کامل

ربات آماده تنظیم است!
